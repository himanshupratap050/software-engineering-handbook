## 1. Exam-Ready Definition
A **software quality framework** is an organised set of standards or models used to assess and improve an organisation's software process quality. Major examples are **CMM/CMMI**, **ISO 9001** and **Six Sigma**.

## 2. Core Concept

**CMM (Capability Maturity Model)** rates the process maturity of an organisation on five levels.

| Level | Name | Idea |
|---|---|---|
| 1 | Initial | Ad hoc, chaotic, depends on individuals |
| 2 | Repeatable (Managed in CMMI) | Basic project management; past success can be repeated |
| 3 | Defined | Organisation-wide standard process, documented and tailored |
| 4 | Managed (Quantitatively Managed in CMMI) | Process and product measured and controlled with numbers |
| 5 | Optimizing | Continuous improvement, defect prevention |

Example key areas: Level 2 - requirements management, project planning, project tracking, SQA, configuration management. Level 3 - peer reviews, training, integrated management. Level 4 - quantitative process management. Level 5 - defect prevention, process change management.

**ISO 9001** is a generic international standard for a *quality management system* of any organisation. It is a **certification** (pass or fail) based on documented procedures and continual improvement. ISO/IEC 90003 gives guidance for applying ISO 9001 to software.

**Six Sigma** is a data-driven approach to reduce defects, aiming at about **3.4 defects per million opportunities**. It uses the **DMAIC** cycle: Define, Measure, Analyze, Improve, Control.

## 4. Advantages, Disadvantages and Comparisons

| Basis | CMM / CMMI | ISO 9001 |
|---|---|---|
| Scope | Software (and systems) specific | Generic, any industry |
| Result | Maturity level (1-5) | Certified or not |
| Focus | Process improvement path | Meeting a minimum quality system |
| Improvement | Built-in staged growth | Continual improvement requirement |

## 5. Key Points for Revision
- Five CMM levels: Initial, Repeatable, Defined, Managed, Optimizing.
- ISO 9001 = certification of a quality management system.
- Six Sigma: 3.4 DPMO, DMAIC.
- CMM is software specific, ISO 9001 is generic.

## 9. Common Exam Mistakes and Confusing Pairs
- Mixing level names (Repeatable is 2, Defined is 3).
- Saying ISO 9001 gives a "level". It gives certification.
- Confusing **CMM level** with **Six Sigma level**.
