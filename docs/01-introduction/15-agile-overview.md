## 1. Exam-Ready Definition
**Agile** is a family of iterative, people-centred approaches that deliver working software in short cycles and welcome changing requirements. Common agile methods are **Scrum** and **Extreme Programming (XP)**.

## 2. Core Concept
**Agile Manifesto (2001) values**
1. Individuals and interactions over processes and tools.
2. Working software over comprehensive documentation.
3. Customer collaboration over contract negotiation.
4. Responding to change over following a plan.

**Scrum**
- Roles: Product Owner, Scrum Master, Development Team.
- Artifacts: Product Backlog, Sprint Backlog, Increment.
- Events: Sprint (commonly 1-4 weeks), Sprint Planning, Daily Scrum, Sprint Review, Sprint Retrospective.

**XP practices:** pair programming, test-driven development, continuous integration, refactoring, small releases, simple design, collective code ownership, planning game.

## 3. Diagram

```
Product Backlog -> Sprint Planning -> Sprint (Daily Scrum) -> Increment -> Review -> Retrospective -> next sprint
```

## 4. Advantages, Disadvantages and Comparisons

| Advantages | Disadvantages |
|---|---|
| Handles change, frequent delivery, customer involvement | Less documentation, hard for large fixed-price contracts, needs a disciplined team |

## 5. Key Points for Revision
